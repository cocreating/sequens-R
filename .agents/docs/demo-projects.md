# Bundled demo-project library

Status: twenty rhythm-archetype demos implemented with automated structural acceptance on 2026-09-06. Human listening approval remains open.

The catalog replaces the former fifteen Synth-first classical-title projects. Each demo rebuilds a recognisable rhythmic archetype from the recorded history of electronic music — a Detroit loop, a krautrock motorik pulse, a Chicago jack, a Cologne schaffel limp, a Berlin School sequencer run, a Kraftwerk-lineage electro displacement — using only this instrument's deterministic generators. What is borrowed is the grid and the gesture. No melody, bass line, chord progression or other authored material is taken from the records that inspired a demo, and no demo carries an artist or record name in its title.

## Shipping contract

- `public/projects/index.json` is the validated catalog consumed by the Workspace demo picker. It contains exactly twenty schema-version-7 projects generated by `scripts/generate-demo-projects.ts`, classified through a required `genre` field.
- The picker presents three genres in catalog order — Minimal Techno (7), Minimal House Techno (7), and Ambient Techno & Breakbeats (6).
- **At most four drum sounds per demo.** A demo names at most four of the eight drum lanes, and `drumParamVariants` masks every unnamed lane to zero, so the limit holds in all eight pattern slots and therefore in all four scenes. `createDrums` throws if a spec declares a fifth sound.
- **At most three modules per demo, at least two.** Seventeen use three and three use two: Purpose Signal, Selected Drift, and Sequencer Field.
- **Synth is no longer mandatory.** Nineteen demos carry one Synth; Sequencer Field is Arp plus Drone, because a Berlin School sequencer piece has no lead voice. Two demos have no Drums: Selected Drift and Sequencer Field.
- Every module has exactly eight deterministic slots. Generated note patterns remain derived data; slots store a stable seed and generator parameters only.
- Each project has four scenes forming one arc rather than four takes: Intro uses slot 2 (every generator's thinnest variant), Groove uses slot 0 (the written pattern), Variation uses slot 5 (displaced, not heavier), and Peak uses slot 3 (the densest variant).
- Tempos range from 84 to 168 BPM. The 168 BPM outlier is Amen Chapel, whose break runs at three times the speed of its pad.
- Mixer is not a module type. Channel levels, pan, sends, shared delay/reverb returns, and master character use the ordinary rack mix state exposed by the permanent header panel.
- Demo files are copied into the production `dist/projects/` output by Vite and fetched on demand. They are not part of the initial PWA shell precache.
- `basic-electro.sequens-r.json` remains an unlisted schema-migration fixture. The fifteen previous demos are listed in `retiredDemoFiles` and are removed on the next generator run.

## Drum lane reference

Lane 0 kick, 1 snare, 2 closed hat, 3 open hat, 4 clap, 5 low tom, 6 rim, 7 FM tom. Specs are written as sparse maps through `laneMap`, so an unnamed lane is silent everywhere.

## Determinism and maintenance

The generator uses fixed labels, seeds, timestamps, sound presets, mix values, and parameter variants. It builds documents through the production project, rack, generator, and sound helpers, then serializes through `projectToJson`; schema validation therefore happens before a file is written.

When editing a demo:

1. Change `scripts/generate-demo-projects.ts`, not a generated JSON file.
2. Run `npm run demos:generate` twice and confirm the second run leaves no diff.
3. Run `npm run check`, `npm test`, `npm run build`, `npm run check:bundle`, and the demo-picker Playwright flow.
4. Audition Groove and all three alternate scenes at matched playback level before release approval. Automated import, schema, and build checks do not replace musical or mix approval.

`tests/unit/example-project.test.ts` imports all twenty catalog files through `projectFromJson` and verifies the exact classified index, the 7/7/6 grouping, schema 7, the 84–168 BPM range, the two-to-three module bounds, at most one Synth, engine-v2 sound state, eight slots, four named scenes, valid scene/module references, generated Synth slot state, and the four-drum-sound ceiling across every slot. `tests/unit/demos.test.ts` covers genre validation and stable grouping. `tests/e2e/phase2.spec.ts` asserts twenty picker entries in 7/7/6 groups and loads Basement Ledger end to end.

The 2026-09-06 regression passes 0 Svelte/TypeScript errors or warnings, 137 unit tests across 20 files, and byte-identical demo regeneration on a second run. The Playwright demo-picker flow, production build, bundle gate, and human listening approval for the twenty mixes and their scene transitions remain to be run on the reference machine.
