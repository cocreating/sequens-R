# Bundled demo-project library

Status: fifteen Piano-forward ambient, minimal, and sweet-electronic demos implemented with automated structural acceptance on 2026-08-28. Human listening approval remains open.

## Shipping contract

- `public/projects/index.json` is the validated catalog consumed by the Workspace demo picker. It contains exactly fifteen schema-version-5 projects generated by `scripts/generate-demo-projects.ts`.
- `npm run demos:generate` deterministically rewrites all fifteen JSON documents and the catalog, and removes the ten retired high-energy genre-demo files. Repeated generation produces byte-identical output.
- The catalog is intentionally Piano-forward: every project contains one authored Piano module; two are Piano-only studies, six use two modules, and seven use three. No project exceeds the three-module ceiling.
- Every module has exactly eight deterministic slots. Every Piano slot contains an editable 16-, 32-, or 64-step pattern derived from the key-aware melody library, with multiple velocity levels and authored accents. Alternate slots demonstrate softer dynamics, displaced entrances, thinner voicings, octave variation, denser finales, and micro-timing.
- Each project has four scenes: Prelude uses slot 4, Theme uses slot 0, Variation uses slot 1, and Finale uses slot 3.
- Tempos range from 56 to 126 BPM. The three explicitly electronic hybrids remain sweet and restrained at 108, 118, and 126 BPM; no shipping demo exceeds 130 BPM.
- The musical ideas are original scale-degree motifs inspired by public-domain-era forms and techniques—Invention, Nocturne, Canon, Sarabande, Largo, Minuet, Waltz, Fugue, Étude, and Rondo—not transcriptions or quotations of a master melody.
- Demo files are copied into the production `dist/projects/` output by Vite and fetched on demand. They are not part of the initial PWA shell precache.
- Demos never persist a Mixer module. Channel levels, pan, sends, shared delay/reverb returns, and master character use the ordinary module/rack mix state exposed by the permanent Mixer view.
- `basic-electro.sequens-r.json` and `basic-electro2.sequens-r.json` remain unlisted compatibility fixtures for schema migration tests. Unlisted local `Basic Electro 4` and `Basic Electro 5` experiments are also outside the shipping catalog.

## Determinism and maintenance

The generator uses stable labels and fixed seeds for project IDs, module IDs, slot seeds, authored patterns, timestamps, sounds, and mix values. It builds documents through the production project, Piano melody, Piano dynamics, and sound helpers, then serializes through `projectToJson`; schema validation therefore happens before a file is written.

When editing a demo:

1. Change `scripts/generate-demo-projects.ts`, not a generated JSON file.
2. Run `npm run demos:generate` twice and confirm the second run leaves no diff.
3. Run `npm run check`, `npm test`, `npm run build`, and the demo-picker Playwright flow.
4. Audition Theme and all three alternate scenes at matched playback level before release approval. Automated import, schema, and build checks do not replace musical or mix approval.

`tests/unit/example-project.test.ts` imports all fifteen catalog files through `projectFromJson` and verifies the exact index, schema 5, the 130 BPM and three-module ceilings, engine-v2 sound state, eight slots, four scenes, valid scene/module references, authored Piano patterns, varied velocities, accent velocity, editor pitch bounds, and the absence of Mixer modules. The two unlisted Basic Electro fixtures retain separate migration coverage.

Post-catalog verification on 2026-08-28 passed with 0 Svelte/TypeScript errors or warnings, 122 unit tests across 18 files, a production PWA build at 115.14 KiB initial JavaScript gzip against the 200 KiB limit, and all 56 Playwright tests. The browser mix regression measured −15.54 LUFS-I / −3.07 dBTP for five modules and −13.49 LUFS-I / −1.17 dBTP for fourteen modules; scheduler-message jitter measured 0.679 ms σ. These checks validate structure, integration, and engine safety, not the open human listening gate for the fifteen musical mixes.
